# Indeks Dokumen Daftar Pustaka (Bab I & Bab II)

Berkas pada folder ini merupakan salinan dokumen sumber resmi, artikel *open-access*, dan literatur primer metode penelitian untuk Daftar Pustaka `[1]`-`[24]` (Bab I) serta `[25]`-`[35]` (Bab II). Berkas biner `.pdf` di folder ini diabaikan oleh `.gitignore` agar repositori Git tetap ringan, tetapi tersimpan lengkap di direktori lokal OneDrive Tugas Akhir.
